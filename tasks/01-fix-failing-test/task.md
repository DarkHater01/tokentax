# Task: fix-failing-test

A 30-line Python module ships with one bug and a test that fails.
Fix the module so the hidden test suite passes.

Rules:
- Change only the module; do not edit the tests.
- Keep the public function signatures unchanged.
- Standard library only.

Denominator note: the minimal trajectory is read the spec, read the module,
write the one-line fix, run the tests.
